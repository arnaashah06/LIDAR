How to Run Native Spatial Sentinel on Your Devices

Notice: This Windows environment does not have macOS Xcode, which is why this high-performance Web LiDAR simulator has been provided to test every feature right away. Flutter has also been installed at C:\src\flutter.

Option A: Native iOS (SwiftUI + ARKit LiDAR)

Requires macOS + Xcode 15+ and an iPhone / iPad with LiDAR.

1. Open "Lidar-ios.xcodeproj" in Xcode on macOS
2. Select your LiDAR iPhone/iPad as build target
3. Enable Camera & Motion capabilities
4. Press Cmd+R to build and run on device

Option B: Flutter Cross-Platform (SpatialSentinel)

Flutter is now installed on this machine and web compiled:

cd Lidar-ios/SpatialSentinel
flutter run -d chrome    # Live in Chrome
